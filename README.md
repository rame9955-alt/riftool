# Riftool

Chrome-Erweiterung (Seitenleiste) für das Browserspiel [Capital Rift](https://play.capitalrift.com).
*English below.*

## Was sie kann

- **Lager:** Bestand pro Ware und Ort, sortierbar nach Wert, Anzahl, Stückpreis oder Name. Dazu deine offenen Marktaufträge, Waren, die nirgends gebraucht werden, und „Verkaufen…“ direkt aus der Liste, auch in Schritten, die jeweils knapp unter dem günstigsten Angebot bleiben.
- **Fabriken:** Maschinen pro Ort mit Rezept, Verbrauch und Produktion pro Minute.
- **Engpässe:** Was wo fehlt und warum, mit Tipps. Auf Wunsch wird nicht abgeholte Ware automatisch dorthin geliefert, wo sie gebraucht wird.
- **Firma wechseln** direkt in der Leiste. Das Spiel braucht dafür einen Computer in einem deiner Räume.
- **Deutsch und Englisch** (Knopf „EN“ bzw. „DE“).

Die Erweiterung nutzt dieselben Anfragen wie das Spiel und deine bestehende Anmeldung im Browser. Sie speichert kein Passwort und schickt nichts an andere Server.

## Installieren

1. Dieses Repository als ZIP herunterladen und entpacken.
2. In Chrome `chrome://extensions` öffnen und oben rechts den **Entwicklermodus** einschalten.
3. **Entpackte Erweiterung laden** klicken und den entpackten Ordner wählen.
4. `play.capitalrift.com` öffnen, anmelden und auf das Riftool-Symbol klicken.

## English

Chrome extension (side panel) for the browser game [Capital Rift](https://play.capitalrift.com).

- **Storage:** stock per item and location, open market orders, unused goods, and selling from the list, including step-wise selling that stays one cent below the cheapest offer.
- **Factories:** machines per location with recipe, consumption and output per minute.
- **Bottlenecks:** what is missing where and why, plus optional automatic delivery of uncollected goods to where they are needed.
- **Switch company** from the panel. The game requires a computer in one of your rooms.
- **German and English** UI.

The extension uses the same requests as the game and your existing browser login. It stores no password and sends nothing to other servers.

**Install:** download and unzip, open `chrome://extensions`, enable **Developer mode**, click **Load unpacked** and select the folder, then open `play.capitalrift.com` and click the Riftool icon.
